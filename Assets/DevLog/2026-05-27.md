# DevLog 2026-05-27

OPP / 온라인 / 전투(HP·효과) 시스템 제거 후, 싱글플레이 타임어택 베이스로 재정비 완료. 현재 구현된 시스템과 공식 정리.

---

## 1. 게임 루프 (`MainFlow`)

- 싱글플레이 / 타임어택 / 점수 누적 구조
- 글로벌 타이머: `gameDuration` (기본 120s) 감산 → 0 도달 시 `EndGame()`
- 라운드 시퀀스 (`DoEndTurn` 코루틴)
  1. `EvaluateSlots()` — 5슬롯 조합 점수 산출
  2. 점수 UI 표시 (`scoreDisplayTime` 동안)
  3. `ResolveJokers()` — 조커를 최적값으로 확정
  4. `_totalScore += turnScore` 누적 → `totalScoreText` 갱신
  5. `ClearPlayerSlots()` — 슬롯 카드 파괴
  6. `DrawCards()` — 손패 6장 유지 (`6 - 손패 - 슬롯`만큼 보충)
  7. `Exp.AddExpAnimated(turnScore)` 호출, 레벨업 시 `Roulette.SpinAndReward()` 콜백 체인
- 일시정지 조건: `_isTransitioning || IsRouletteActive`
- 게임 종료: `canPlaceInSlot=false`, EndTurn 버튼 숨김, 콘솔 총점 로그

## 2. 덱 시스템 (`Deck`)

- 그룹 단위 카드 풀 (`DeckGroup[]`)
  - 각 그룹: 7장 슬롯 (`cards[0..5]` = 값 1~6, `cards[6]` = 조커)
  - `isActive` 토글로 그룹 단위 ON/OFF
- 손패 한도: `maxCards` (기본 8)
- 초기 드로우: `drawCount` (기본 6)
- 배치: 아치형 (위로 볼록)
  - `angleRange = baseAngleRange + max(0, count - drawCount) × anglePerCard`
  - `t = (i / (total-1)) - 0.5` (총 1장이면 0)
  - `pos = (sin θ, cos θ - 1, 0) × archRadius`
  - `rot.z = -t × angleRange`
- 인터랙션
  - Hover: `Physics2D.OverlapPointAll` → 가장 높은 `sortingOrder` 카드 선택
  - 떨림 방지: 호버 카드의 base 영역 내면 호버 유지
  - 드래그: 좌클릭 시작 → 마우스 추종 → 슬롯 위 드롭 시 `Slot.PlaceCard()`
- 정렬: `SortByNumber()`, `SortByType()` (타입 우선 → 숫자 보조)

## 3. 카드 (`CardValue`, `CardHover`)

- `CardValue`: `value`, `isJoker`, `cardType`, `poolIndex`
- `CardType` enum: `Attack`, `Critical`, `Heal`, `Chain` (현재 로직 무관, 그룹 분류용으로 유지)
- `CardHover` 책임
  - `SetBase(pos, rot, sortingOrder)` — 아치 기준 위치 캐싱
  - `Hover()` / `Unhover()` — 부드러운 보간으로 위로 띄움
  - `TriggerWave(amount)` — 감쇠 사인파로 출렁임 연출
  - `StartDrag()` / `UpdateDrag()` / `EndDrag()` — 드래그 상태 전환

---

## 4. 슬롯 (`Slot`)

- 상태: `_placedCard`, `_placedCardValue`, `_placedCardIsJoker`, `_placedCardType`
- `PlaceCard(card)`
  - 기존 카드 파괴 → 새 카드 child화 → `FitToSlot` 스케일 보정
  - `CardHover.enabled = false`, 자식 콜라이더 모두 disable
  - `Renderer.sortingOrder = 1`
- `PlaceCardRaw(card)` — 스케일 보정 없이 배치 (리롤 결과 카드용)
- `ReleaseCard()` — 파괴 없이 슬롯에서 분리 (참조 반환)
- `ClearCard()` — 파괴
- 우클릭 반환
  - `_lastReturnFrame` 가드로 같은 프레임 다중 슬롯 처리 차단
  - `ReturnAnimation` 코루틴: 0.2s 스케일 축소 → `Deck.AddCardByValue` 또는 `AddJokerCard`
- `FitToSlot`: `scale = min(slotW / cardW, slotH / cardH)`

## 5. 슬롯 리롤 (`SlotRerollHandler`)

- 횟수: `_remaining` 시작 = `_maxRerolls` (기본 2), 새 라운드마다 `+1`까지 충전
- 트리거: 손패가 채워진 슬롯 위에 마우스 호버 + 좌클릭
- 쿨다운: 카드 배치 후 0.5초 동안 리롤 불가
- 오버레이: `RadialFill` 셰이더로 잔여 비율 (`remaining / maxRerolls`) 부채꼴 표시
- 슬롯머신 연출 (`DoSlotReroll`)
  - 최종 카드 선결정: `Deck.GetRandomPrefabOfType(type)` (동일 타입 풀)
  - 릴 카드 10장 생성, 마지막 3장(`finalZone`)은 최종 카드로 고정
  - 슬라이드 거리 = `cardSpacing × (reelCount - 1)`, duration 1.2s, ease-out cubic
  - `eased = 1 - (1-t)^3`
  - SpriteMask로 슬롯 영역만 보이게 클리핑
  - 종료 후 `PlaceCardRaw(finalCard)` → 마스크/릴 컨테이너 파괴

## 6. 점수 평가 (`GameFlow`)

### 6.1 조합 우선순위 (위부터 평가, 먼저 매칭되면 채택)

| 순위 | 조합 | 공식 |
| ---- | ---- | ---- |
| 1 | 파이브카드 | `95 + val × 0.5` |
| 2 | 포카드 | `80 + fourVal × 1 + kicker × 0.1` |
| 3 | 풀하우스 | `65 + tripleVal × 1 + pairVal × 0.1` |
| 4 | 스트레이트(하이) (2-6) | `70` |
| 5 | 스트레이트(로우) (1-5) | `65` |
| 6 | 스몰스트레이트 (4연속) | `56 + highVal × 0.5` (3456→59, 2345→58.5, 1234→58) |
| 7 | 트리플 | `40 + tripleVal × 2 + bigKicker × 0.3 + smallKicker × 0.1` |
| 8 | 투페어 | `25 + bigPair × 2 + smallPair × 0.3 + kicker × 0.1` |
| 9 | 원페어 | `10 + pairVal × 2 + bigKicker × 0.5 + midKicker × 0.2 + smallKicker × 0.1` |
| 10 | 하이카드 | `top × 2 + 2nd × 0.8 + 3rd × 0.3 + 4th × 0.1` |

### 6.2 조커 최적 해석 (`ResolveJokersOptimal`)

- 조커 N장 → `6^N` 조합 brute-force
- 각 조합으로 `EvaluateHand` 호출, 최고 점수 채택
- 결과: `bestValues[]` — 조커 자리에 최적 숫자 채워진 배열

### 6.3 기여 슬롯 마킹 (`FindContributingIndices`)

- 조합별 규칙에 따라 점수에 기여한 슬롯만 bool 마킹
- 풀하우스: 트리플 3장 + 페어 2장
- 스트레이트류: 시퀀스에 속한 unique 값 한 번씩
- 하이카드: 최댓값 슬롯 1개

### 6.4 실시간 표시 (`Update`)

- `GetContributingSlots()` → `CurrentBestScore`, `CurrentBestRule` 매 프레임 갱신
- 기여 슬롯에 `effectContribute` 스프라이트 어태치
- 호버/드래그 중 카드에 `effectHover` 어태치
- 손패 카드 중 슬롯 빈 자리에 넣었을 때 최고점이 되는 카드에 `effectBestPick` 어태치
  - `ResolveJokersOptimal(slot + 손패 전체)` → 기여 인덱스 중 손패 자리만 표시

## 7. EXP (`Exp`)

- 레벨업 필요 EXP: `expPerLevelStep × currentLevel` (1Lv=100, 2Lv=200, …)
- `AddExpAnimated(amount, onLevelUp)` 코루틴
  - 남은 양이 현재 레벨 잔여 공간보다 작으면 바만 채움
  - 크면 바 풀 → `ShowLevelUp()` → `onLevelUp()` (룰렛) 대기 → 다음 레벨 진입
- 애니메이션
  - 바 채움: `duration = max(0.15, fillDuration × (toRatio - fromRatio))`, ease-out quad `1 - (1-t)^2`
  - LEVEL UP 펄스: 0~0.3 구간 `1 → 1.08`, 0.3~1 구간 `1.08 → 1`, 텍스트 알파 `sin(t × 4π)`
  - 금색 바 + "LEVEL UP!" 텍스트는 콜백 종료까지 유지

## 8. 룰렛 (`Roulette`)

- 5개 세그먼트 (각 색상별 시작/끝 각도, 카드 풀)
- `SpinAndReward()` 호출 시
  - 룰렛 슬라이드 인 (`slideDuration`)
  - 휠 회전 (`spinDuration`) → 포인터 기준 세그먼트 판정 (0°=12시 방향, 시계 방향)
  - 결과 패널 표시: 세그먼트별 배경 + 카드 풀에서 1장 랜덤 → `ResultCardPrefab`
  - 리롤 버튼 (`maxRerolls`까지 재추첨)
  - 확정 시 `ResultSegment`, `ResultCardPrefab` 외부 노출
- `IsSpinning` 동안 `MainFlow` 타이머 정지
