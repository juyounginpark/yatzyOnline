# DevLog Day 3 — 공격/방어 전투 판정 & 연출

- 작성일: 2026-05-26
- 대상 스크립트: `Scripts/Game/MainFlow.cs`, `Scripts/Game/TurnAnimator.cs`, `Scripts/Game/HP.cs`, `Scripts/Game/Effects/*`

---

## 1. 기능 의도

- 한 라운드 = **두 플레이어가 번갈아 1턴씩** → 둘 다 끝나면 전투 판정(Resolution Phase)
- 필드를 통째로 **공격(앞면) ↔ 방어(뒷면, Guard)** 로 전환하는 심리전 도입
  - 공격: 점수만큼 상대 본체에 데미지
  - 방어: 상대 공격을 막거나 받아치되, 카드 일부를 잃는 리스크
- 점수가 곧 데미지인 구조 위에 **"질러야 하나 막아야 하나"** 의 수 싸움 레이어 추가
- 결과를 카메라 연출로 극화 — 판이 끝나는 순간의 긴장감 연출

---

## 2. 진행 — 라운드/턴 오케스트레이션

- `MainFlow`를 오케스트레이터로 두고 실제 로직은 서브시스템에 위임
  - `TurnAnimator` (연출 코루틴) / `CardEffectPipeline` (카드 효과) / `ChainDotSystem` (체인 DOT) / `SlotRerollHandler` (리롤)
- 상태머신
  - 라운드 첫 턴 종료 → 상대로 턴 넘김(`_isRoundSecondTurn = true`)
  - 라운드 둘째 턴 종료 → `ResolutionPhaseRoutine()` 진입
  - 판정 후 선공 교대(`_firstPlayerInRound` 토글)

---

## 3. 진행 — 필드 단위 Guard

- 플레이어 필드는 **전부 Attack 또는 전부 Guard** (한 칸 뒤집으면 전체 동시 뒤집힘)
- `ToggleFieldGuard()` : 슬롯 좌클릭으로 필드 전체 뒤집기 토글
- `OnPlayerCardPlaced()` : 새 카드를 놓으면 무조건 전체 앞면(Attack)으로 복귀
- 잔류 Guard(직전 라운드 생존)가 있으면 새 턴을 Guard 모드로 시작

---

## 4. 진행 — 전투 결과 매트릭스

- `FieldOutcome` 열거: `None / Fly / Grave / Survive / Stay`
- 판정 규칙 (`ResolutionPhaseRoutine`)
  - **카드 vs 빈 필드** : 공격이면 발사(Fly), Guard면 잔류(Stay) — 심리전
  - **공격 vs 공격** : 양측 본체에 각자 점수만큼 데미지, 양측 카드 소모
  - **공격 vs Guard** : 점수 우열로 차단/관통 결정 — Guard 승리 시 공격 무덤(Grave)+Guard 생존(Survive), 공격 승리 시 차이만큼 데미지
  - **Guard vs Guard (올인 대치)** : 높은 쪽 생존+두 점수 **합산 데미지**, 낮은 쪽 전멸, 동점은 양측 파괴·노데미지

---

## 5. 진행 — 연출 (TurnAnimator)

- `PanAndRevealSlots()` : 카메라 줌인 후 카드를 **순차 조명**, 마지막 카드는 느린 뒤집기 + 점증 셰이크(`TensionShake`)로 클라이맥스
- 전투 시 양 진영 카드를 원점 기준 위/아래 두 행으로 모아 **대치**(`GatherBothToCenter`)
- 충돌 연출 분기
  - `MutualAttackClash` (공격 vs 공격)
  - `UnifiedCombatStrike` (한쪽 관통)
  - `BlockAndShatter` (공격이 Guard에 막혀 산산조각)
  - `MutualDestructionClash` (무승부 동반 파괴)
- 본체 피격: `ApplyBodyDamage()`에서 HP 차감 + 대상/카메라 셰이크

---

## 6. 진행 — 방어 생존 룰렛

- Guard 생존 시 **0~3장 랜덤 파괴 후 나머지 패 복귀** (`ProcessGuardSurvivors`)
  - 1장: 50% 파괴 / 2장 이상: 최소 절반 생존 보장(2→1, 3→1, 4→2, 5→2)
- `SpinRoulette()` : 테두리가 후보 카드를 2~3바퀴 돌다 막바지 감속하며 한 칸에 멈춤 → 당첨 카드 덱 앵커로 날려 소멸
- 룰렛 중에는 `GameFlow`의 일반 이펙트 갱신을 멈춰 카드 파괴와의 충돌 방지(`ShowRouletteEffect`/`ClearRouletteBorder`/`HideRouletteEffect`)

---

## 7. 진행 — 카드 효과 파이프라인

- `CardEffectPipeline` : 효과를 `Order`로 정렬해 턴 종료 시 순차 실행
  - `OffensiveEffect` / `ChainEffect` / `HealEffect`
- 슬롯에서 카드 해제 시 타입별 분류, 체인 미매칭 카드는 Attack으로 강등
- 체인 카드: 같은 값 2장 이상 매칭 시 다음 턴까지 슬롯 잠금(`ChainDotSystem` DOT 틱)
