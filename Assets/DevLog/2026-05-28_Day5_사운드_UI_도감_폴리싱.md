## 1. 기능 의도

- 기능 완성 단계에서 **체감 품질(juice)** 보강 — 동일한 판정도 소리·연출이 붙으면 전혀 다른 게임감
- 신규 플레이어가 룰을 몰라도 되도록 **족보 도감** 제공
- "지금 누구 턴인지 / 방금 무슨 족보로 몇 점인지"를 명확히 알리는 **정보 전달 UI**

---

## 2. 진행 — 사운드 매니저 (SoundManager)

- 싱글톤 + `DontDestroyOnLoad`, 3채널 분리: **BGM / SFX / 시계(루프 전용)**
- SFX 카테고리 정리
  - UI/기본: `uiClick`, `cardHover`, `cardDraw`, `cardPlace`, `cardFlip`, `turnEnd`, `clockTick`, `rouletteSpin/Select`
  - 전투: `cameraPan`, `tensionShake`, `gatherPower`, `combatHit`, `combatBlock`, `shatter`, `damageTaken`
  - 결과: `heal`, `victory`, `defeat`
- 시계 소리 = 내 턴 + 타이머가 실제로 흐를 때만 루프(`StartClock`/`StopClock`) — 드래프트/전환/상대 턴엔 정지
- 기존 시스템에 침습 최소화: 호출부는 전부 `SoundManager.Instance != null` 널 가드 후 `PlaySFX` (사운드 미할당이어도 동작)

---

## 3. 진행 — 결과 UI (ResultUI)

- 판정 시 **마지막 카드 뒤집기 타이밍에 맞춰** 콤보명+점수 페이드인
  - `ShowResult(combo, score, fadeOverride)` — 뒤집기 소요시간을 페이드인 시간으로 덮어써 **연출 싱크**
  - `minFloatTime`(기본 2초) 보장 후 상대편으로 넘어갈 때 페이드아웃
- 캔버스를 Screen Space - Overlay로 강제 → **카메라 줌/팬 연출과 무관**하게 항상 정위치 표시
- 플레이어/상대 공용 TMP 하나를 재사용

---

## 4. 진행 — 턴 표시 (WhoSTurn)

- 현재 **공격 턴 주인**(`MainFlow.IsPlayerAttackTurn`)을 텍스트로 표시
  - 내 공격: "Your Attack Turn" (빨강) / 상대 공격: "Opp's Attack Turn" (파랑)
- 매 프레임 폴링하되 **상태 변화 시에만 갱신**(`_lastIsPlayerAttack` 캐시)으로 비용 절감

---

## 5. 진행 — 족보 도감 (Book / BookOpen)

- 스크롤 뷰 Content에 콤보마다 Page 프리팹을 코드로 생성·정렬 (Layout Group 불필요)
- 콤보 목록을 낮은 점수→높은 점수 순으로 정의, 카드 스프라이트(숫자 1~6 + 조커) 매핑
- 핵심: **조합 기여 카드 자동 하이라이트**
  - `ComputeContributingIndices()` — cardValues에서 실제 조합 카드를 역산(풀하우스/스트레이트/투페어 등)
  - 기여 카드 위에 `effectContribute` 오버레이 → 게임 내 하이라이트와 **동일한 시각 언어**
- 에디터 편의: `[ContextMenu("Build Pages")]`로 편집 모드에서 생성·씬 저장 (런타임 매번 재생성 안 함)
- `BookOpen` : 버튼으로 도감 판넬 on/off 토글 (시작 시 off)
