# DevLog Day 4 — 온라인 멀티플레이 (뒤끝 인게임 릴레이)

- 작성일: 2026-05-27
- 대상 스크립트: `Scripts/Server/NetworkManager.cs`, `Scripts/Server/GamePacket.cs`, `Scripts/Game/OnlineOpponent.cs`

## 1. 기능 의도

- 뒤끝(Backend) v5.18 **인게임 멀티플레이 릴레이**로 1:1 실시간 대전 구현
- 별도 서버 로직 없이, 양 클라이언트가 **JSON 패킷을 릴레이**해 서로의 상태를 재현하는 P2P-라이크 구조
- 오프라인 AI(`OppAuto`)와 **동일한 연출 코드를 공유**하되 상대 입력만 네트워크로 대체
- 끊김·중복·자기 패킷 등 릴레이 환경 특유의 문제를 견디는 견고함 목표

## 2. 진행 — 접속 파이프라인 (NetworkManager)

- 상태머신 `NetState` : `Idle → LoggingIn → LoggedIn → ConnectingMatchServer → Matching → Matched → InGame`
- 흐름
  1. 게스트 로그인 + 닉네임 자동 설정 (에디터는 `dataPath` 해시로 인스턴스별 고유 계정 → ParrelSync 대응)
  2. 매칭 서버 접속 → 룸 생성 → `RequestMatchMaking`
  3. 매칭 응답에서 게임 서버 주소/룸 토큰 수신
  4. 게임 서버 접속 → 세션 목록 수신 = **양쪽 입장 완료 = 게임 시작**
- SDK 콜백 내부에서 `JoinGameServer` 직접 호출 시 충돌 → **다음 Update 프레임으로 지연 실행** (`_pendingGameToken`)
- 게임 서버 접속 실패 시 `MaxJoinRetries`(3회) / `JoinRetryDelay`(2초) **자동 재시도**
- 선후공 결정: `IsSuperGamer()` = 호스트 = 선공(`IGoFirst`)

---

## 3. 진행 — 패킷 프로토콜 (GamePacket)

- LitJson 기반 경량 JSON, 키를 1~2글자로 축약해 대역폭 절감
- `PacketType` 6종
  - `GameReady(0)` — (씬 이동은 세션 목록으로 처리, 릴레이 불필요)
  - `TurnEnd(1)` — 슬롯 카드 배열 + 체인잠금 인덱스(`cl`) + 필드 Guard(`g`) + 양측 HP(`shp`/`rhp`)
  - `CardPlace(2)` / `CardReturn(3)` — 슬롯 실시간 배치·회수
  - `GameOver(4)` — 승패
  - `Sync(5)` — 실시간 타이머(0.01초 단위) + HP 동기화
- `SlotCardData` : 값 0(빈 칸)은 직렬화에서 생략해 패킷 최소화

---

## 4. 진행 — 수신 처리: 폴링 큐

- 이벤트 콜백에서 직접 게임 로직을 건드리지 않고 **큐/필드에 저장 → MainFlow.Update에서 폴링** (스레드/타이밍 안전)
  - `IncomingCardPlaces` / `IncomingCardReturns` (Queue)
  - `IncomingTurnEnd` / `IncomingChainLockIndices` / `IncomingFieldGuard` / HP (단발 필드 + `Consume...`)
  - `HasIncomingSync` 플래그 기반 Sync
- **자기 패킷 무시**: 송신 시 `from`에 클라이언트 고유 ID 삽입, 수신 시 동일 ID면 드롭 (릴레이 에코 방지)

---

## 5. 진행 — 상대 재현 (OnlineOpponent)

- NetworkManager 큐에서 받은 데이터를 상대 턴 연출로 변환 (코루틴은 이 컴포넌트가 소유)
  - `HandleCardPlaced` : 상대 슬롯에 **뒷면 카드** 스폰 + 배치 애니메이션
  - `HandleCardReturned` : 슬롯 회수
  - `HandleTurnEnd` : 수신 슬롯 데이터로 상대 필드 복원 후 전투 판정에 합류
- `RevealGuardCardRoutine` : 판정 시 상대 Guard 카드 공개 연출 (오프라인 `OppAuto`와 동일 인터페이스)

---

## 6. 진행 — 실시간 동기화

- 내 턴 동안 `SyncInterval`(1초)마다 `SendSync(타이머, 내 HP, 상대 HP)` 전송
- 상대 턴엔 로컬 카운트다운 정지, **Sync로 받은 타이머/HP 반영**
- `ApplyHpSync` : 수신 HP와 현재 HP 차가 1 이상일 때만 데미지/회복 애니메이션 적용 (미세 흔들림 방지)
- HP 관점 변환: 보낸 쪽 기준 `senderHp`=상대 HP, `receiverHp`=내 HP로 좌우 반전 매핑

## 7. 예외 처리 / 디테일

- 세션 목록 중복 수신 → 이미 `InGame`이면 무시
- 상대 오프라인 → `OnOpponentDisconnected` 이벤트
- 온라인 모드 진입 시 `OppAuto` 비활성, `OnlineOpponent` 없으면 런타임 자동 생성
- 하위 호환: 구 코드용 `PendingTurnEnd`/`ConsumePendingTurnEnd` 별칭 유지
